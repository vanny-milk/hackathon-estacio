# Camada Frontend

Esta pasta abriga a interface de usuário do projeto:

- **`components/`**: Componentes atômicos e primitivos reutilizáveis em qualquer parte da aplicação (Botões, Modais, Inputs, Badges, Loaders).
- **`features/`**: Módulos divididos por contexto de negócio (ex: `auth`, `dashboard`, `orders`), agrupando telas, hooks e componentes específicos daquela funcionalidade.
- **`layouts/`**: Estruturas de página e cascas visuais (ex: barra de navegação superior, menu lateral, rodapé).
- **`services/`**: Clientes HTTP e funções de comunicação assíncrona com o backend.
- **`styles/`**: Configurações de tema, tokens visuais e estilos globais.
